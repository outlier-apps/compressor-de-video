# Compressor de Vídeo

Programa para Windows que comprime, converte (MP4, MOV, WEBM, GIF, MP3), corta, extrai o áudio e junta vídeos.

**Baixar:** [Compressor-de-Video.exe](https://github.com/outlier-apps/compressor-de-video/releases/latest/download/Compressor-de-Video.exe)

Precisa de uma chave de ativação, vendida na Basefy.

## Requisitos

- Windows 10 ou 11 (64 bits)
- Internet (para ativar a chave)

## Como usar

1. Baixe e abra o `Compressor-de-Video.exe`. Ele cria um atalho na Área de Trabalho.
2. Cole a chave de ativação e clique em **Ativar**.
3. Arraste os vídeos, escolha o que fazer e clique em **Processar**. O arquivo novo é salvo ao lado do original.

Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações** e depois em **Executar assim mesmo**.

O programa avisa sozinho quando sai uma versão nova.

## Componentes de terceiros

Este programa inclui o [FFmpeg](https://ffmpeg.org) (licença GPL), cujo código-fonte está disponível em https://ffmpeg.org/download.html.
